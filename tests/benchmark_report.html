Operators and expressions are measured twice. Codegen is the first call, the one that generates and compiles the function — each sample builds a fresh Algebra and times only that call, so no first call is secretly a cache hit. Steady state is the same call once the generated function is cached.

Every figure is a min, never a mean: scheduler noise only ever adds time. Hover any mark for the median and the sample count behind it. Algebra construction does no codegen, so it has one number, not two.
